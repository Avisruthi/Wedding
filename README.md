## Publish with GitHub Pages
1. Sign in at https://github.com (free account).
2. Click + (top right) > New repository. Name it e.g. `wedding`. Set it to Public. Click Create repository.
3. Click "uploading an existing file". Drag in index.html, Groom.jpg, Bride.jpg, Couple.jpg (and any photoN.jpg). Click Commit changes.
4. Repository Settings > Pages > Build and deployment > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
5. Wait 1-2 minutes. Your link: https://YOUR-USERNAME.github.io/wedding/

## Update later
Open the repo > Add file > Upload files > upload the changed file with the SAME name > Commit. Refresh the link after a minute.
